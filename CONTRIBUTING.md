# Contributing to WOLFBOT

Contributions, bug reports, documentation improvements, and focused feature
pull requests are welcome.

## Before submitting a pull request

- Open an issue first for large or breaking changes.
- Keep each pull request focused on one improvement.
- Do not commit `.env` files, session credentials, API keys, database URLs, or
  local runtime state.
- Keep the existing `wolfsocket` and `wolfbtns` integrations intact.
- Run syntax checks and test the affected command or module.
- Update documentation when behavior or configuration changes.

## Pull request process

1. Fork the repository and create a descriptive branch.
2. Make the change and test it locally.
3. Submit a pull request with a clear summary and testing notes.
4. Respond to review feedback and keep sensitive data out of the branch.
